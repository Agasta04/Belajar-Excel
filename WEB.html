Bagian 01 · Pengantar

Pengenalan Microsoft Excel

Fundamental

Sebelum melangkah lebih jauh, kita perlu mengenal terlebih dahulu apa itu Microsoft Excel, bagaimana bentuk antarmukanya, dan bagaimana cara membaca alamat sel — fondasi dari seluruh pekerjaan pengolahan angka.

Apa Itu Microsoft Excel?

Microsoft Excel adalah program pengolah angka (spreadsheet) yang dikembangkan oleh Microsoft. Excel digunakan untuk mengelola, menghitung, menganalisis, dan menyajikan data — baik dalam bentuk tabel maupun grafik. Hampir semua bidang pekerjaan, dari pendidikan, keuangan, hingga administrasi, memanfaatkan Excel untuk mempercepat pengolahan data.

ANALOGI

Bayangkan Excel seperti buku besar kakek-nenek zaman dulu — tetapi versi digital. Setiap halaman berisi kotak-kotak (cell) yang bisa diisi angka, teks, atau rumus. Bedanya, Excel menghitung otomatis dalam sekejap dan dapat membuat grafik hanya dengan beberapa klik.

Mengapa Excel Penting?

  • Efisien. Menghitung ribuan data tanpa perlu menghitung manual.
  • Akurat. Mengurangi risiko kesalahan hitung.
  • Fleksibel. Data dapat diubah, diperbarui, dan dianalisis kapan saja.
  • Visual. Data dapat disajikan dalam bentuk grafik yang mudah dipahami.

Antarmuka Microsoft Excel

Saat pertama kali membuka Excel, kamu akan melihat beberapa bagian penting. Memahami fungsi setiap bagian akan mempercepat pekerjaanmu.

Bagian Fungsi
Ribbon / Menu Kumpulan tab perintah (Home, Insert, Formulas, Data).
Cells (Sel) Kotak pertemuan baris dan kolom, tempat mengisi data.
Kolom & Baris Kolom berlabel A, B, C…; baris berlabel 1, 2, 3…
Formula Bar Menampilkan isi asli sel — rumus, teks, atau angka.
Sheet Tabs Tab di bagian bawah, berisi lembar kerja.
Name Box Menampilkan alamat sel aktif, misalnya A1 atau B5.
INFO: Tampilan Excel dapat berbeda antarversi (2016, 2019, 2021, atau Microsoft 365). Namun bagian inti seperti Ribbon, Formula Bar, dan Sheet Tabs selalu tersedia.

Sel Aktif dan Name Box

Sel yang sedang dipilih disebut sel aktif, ditandai dengan kotak tebal berwarna hijau atau biru. Alamat sel aktif selalu ditampilkan di Name Box, sedangkan isi lengkapnya muncul di Formula Bar.

Contoh: jika kamu mengklik sel C4, Name Box menampilkan C4, dan Formula Bar menampilkan isi sel tersebut.

Navigasi Cepat dengan Keyboard

Tombol Fungsi
Tab Pindah ke sel di sebelah kanan.
Enter Pindah ke sel di bawah.
Ctrl + Home Kembali ke sel A1.
Ctrl + → Lompat ke kolom paling kanan yang berisi data.
Ctrl + ↓ Lompat ke baris paling bawah yang berisi data.
Ctrl + S Menyimpan file.

Alamat Sel

Setiap sel memiliki alamat unik berdasarkan pertemuan kolom dan barisnya.

A B C D
1 Nama MTK B. Indo B. Ing
2 Budi 85 80 90
3 Ani 92 88 95
4 Cici 78 85 82
5 Dodi 90 92 87
  • Sel B2 berisi 85 — nilai Matematika Budi.
  • Sel A3 berisi "Ani".
  • Penulisan sel selalu mengikuti pola Kolom + Baris.
  • Range B2:D2 mencakup B2, C2, dan D2.
CATATAN: Perhatikan urutan: kolom dulu, baru baris. Menulis 5C adalah salah; yang benar C5.

Range: Beberapa Sel Sekaligus

Range adalah kumpulan beberapa sel yang ditulis dengan tanda titik dua (:).

Range Artinya
B2 Satu sel saja.
B2:D2 Satu baris, tiga kolom.
B2:B5 Satu kolom, empat baris.
B2:D5 Blok data 4 × 3 (12 sel).
RANGKUMAN BAGIAN 1
  • Excel adalah aplikasi pengolah angka dari Microsoft.
  • Antarmuka Excel: Ribbon, Sel, Kolom & Baris, Formula Bar, Sheet Tabs, Name Box.
  • Sel ditulis dengan pola Kolom + Baris, misalnya B2.
  • Range ditulis dengan tanda titik dua, misalnya B2:D2.

Bagian 02 · Manajemen File

Membuat Folder Kerja

Organisasi

Sebelum mulai bekerja dengan Excel, biasanya kita membuat folder khusus untuk menyimpan file. Kebiasaan kecil ini akan sangat membantu saat mengelola banyak tugas.

Mengapa Folder Kerja Penting?

Bayangkan kamu memiliki sepuluh file Excel yang tersebar di Desktop, Downloads, dan Documents. Ketika guru meminta tugas dikumpulkan, kamu akan kesulitan menemukan file yang tepat. Folder kerja membantu menyimpan file secara terstruktur sehingga:

  • Tugas tidak tercampur dengan file lain.
  • File mudah ditemukan kembali.
  • Risiko file tertimpa atau hilang lebih kecil.
  • Kebiasaan kerja menjadi lebih profesional.

Langkah Membuat Folder

1

Buka File Explorer dengan menekan Windows + E.

2

Pilih lokasi penyimpanan, misalnya Documents.

3

Klik kanan pada area kosong → pilih New → Folder.

4

Beri nama folder: Tugas_Excel_Nama_Absen.

5

Buka Excel → buat file baru → simpan di folder tersebut dengan Ctrl + S.

CATATAN: Hindari menyimpan file Excel di Desktop atau Downloads. File di kedua lokasi tersebut mudah tertimpa atau sulit ditemukan kembali.

Format Penamaan File

Penamaan file yang baik mengikuti pola yang konsisten: Tugas_Excel_[Nama]_[Absen]

Contoh Nama File Keterangan
Tugas_Excel_Budi_02.xlsx ✓ Benar — sesuai format baku.
Tugas_Excel_Ani_15.xlsx ✓ Benar — sesuai format baku.
tugas budi.xlsx ✗ Salah — tidak ada absen, ada spasi.
latihan.xlsx ✗ Salah — tidak ada identitas pemilik.

Format Penyimpanan Excel

Format Kegunaan
.xlsx Format standar Excel modern. Untuk pekerjaan sehari-hari.
.xls Format lama. Hanya untuk kompatibilitas aplikasi lama.
RANGKUMAN BAGIAN 2
  • Folder kerja membuat file tersimpan rapi dan mudah ditemukan.
  • Gunakan format penamaan Tugas_Excel_Nama_Absen.
  • Hindari menyimpan file penting di Desktop atau Downloads.
  • Format file standar Excel modern adalah .xlsx.

Bagian 03 · Struktur Data

Membuat Tabel Data

Tabel

Tabel yang baik memiliki header yang jelas dan data yang terstruktur. Tabel yang rapi memudahkan proses analisis dan penyajian data di tahap berikutnya.

Contoh Tabel Nilai

CONTOH DATA NILAI SISWA KELAS X Range A1:D5
A B C D
1 Nama MTK B. Indo B. Ing
2 Budi 85 80 90
3 Ani 92 88 95
4 Cici 78 85 82
5 Dodi 90 92 87

Langkah Membuat Tabel

1

Ketik header pada baris pertama: A1 = Nama, B1 = MTK, C1 = B.Indo, D1 = B.Ing.

2

Isi data siswa di baris 2 ke bawah. Tekan Tab untuk pindah kolom, Enter untuk pindah baris.

3

Blok baris header → klik Bold (Ctrl + B). Beri latar belakang warna muda.

4

Berikan border: Home → Borders → All Borders.

TIPS AUTO-FIT: Letakkan kursor di garis pemisah antar kolom pada header, lalu klik dua kali. Lebar kolom akan menyesuaikan isi secara otomatis.

Format Header yang Disarankan

Aspek Saran
Huruf tebal Gunakan Bold agar header menonjol.
Warna latar Gunakan warna muda agar mudah dibedakan.
Perataan Rata tengah (Center).
Border Gunakan All Borders.
CATATAN PENTING: Jangan mencampur angka dengan teks dalam satu kolom. Menulis "85 poin" pada kolom nilai membuat Excel tidak dapat menghitungnya.

Kesalahan Umum

Kesalahan Akibat
Header tidak diberi format Tabel sulit dibaca.
Data teks di kolom angka Rumus tidak bisa dihitung.
Sel kosong di tengah data Range menjadi tidak valid.
Tidak ada border Tabel tampak berantakan.
RANGKUMAN BAGIAN 3
  • Tabel yang baik memiliki header jelas dan data terstruktur.
  • Gunakan Bold, warna latar, dan Border untuk memperjelas tampilan.
  • Manfaatkan Tab dan Enter untuk berpindah sel.
  • Auto-fit membuat lebar kolom menyesuaikan isi.

Bagian 04 · Kalkulasi

Rumus Dasar Excel

Formula

Inilah inti Microsoft Excel — kemampuan menghitung data secara otomatis. Di bagian ini kita mempelajari operator aritmatika, referensi sel, dan fungsi-fungsi dasar yang wajib dikuasai.

ATURAN UTAMA: Semua rumus di Excel harus diawali dengan tanda sama dengan (=). Tanpa tanda ini, Excel menganggap entri sebagai teks biasa, bukan rumus.

Operator Aritmatika

Operator Fungsi Contoh Hasil
+ Penjumlahan =5+3 8
- Pengurangan =10-4 6
* Perkalian =6*7 42
/ Pembagian =20/4 5
^ Pangkat =2^3 8

Referensi Sel

Kelebihan Excel adalah kemampuannya merujuk ke sel lain dalam rumus. Jika nilai sel berubah, hasil rumus otomatis ikut berubah.

Contoh: =B2+C2+D2 menjumlahkan nilai Matematika, B. Indonesia, dan B. Inggris milik Budi. Hasil: 85 + 80 + 90 = 255.

TIPS CEPAT: Ketik tanda =, lalu klik sel yang ingin dijumlahkan. Excel otomatis menuliskan alamat selnya. Tekan + untuk melanjutkan.

Fungsi Dasar (Built-in Functions)

Fungsi adalah rumus siap pakai dari Excel untuk menghitung banyak data sekaligus.

SUM Penjumlahan

Menjumlahkan semua angka dalam range.

=SUM(B2:D2)
AVERAGE Rata-rata

Menghitung rata-rata dari suatu range.

=AVERAGE(B2:D2)
MAX Nilai Tertinggi

Mencari nilai tertinggi dalam range.

=MAX(B2:B5)
MIN Nilai Terendah

Mencari nilai terendah dalam range.

=MIN(B2:B5)

Penerapan pada Tabel Nilai

  • Total nilai Budi: =SUM(B2:D2) → 255
  • Rata-rata nilai Budi: =AVERAGE(B2:D2) → 85
  • Nilai MTK tertinggi: =MAX(B2:B5) → 92
  • Nilai MTK terendah: =MIN(B2:B5) → 78
PERBEDAAN OPERATOR VS FUNGSI: Operator (+ - * /) untuk perhitungan sederhana antar dua angka. Fungsi (SUM, AVERAGE, MAX, MIN) untuk menghitung banyak data sekaligus.

Kesalahan Umum

Kesalahan Akibat Perbaikan
Lupa tanda = Excel menganggapnya teks. Awali dengan =
Salah alamat range Hasil tidak sesuai. Cek ulang alamat
Range kurang lengkap Data di luar range tidak terhitung. Perluas range
Koma (,) bukan titik dua (:) Range tidak dikenali. Gunakan (:)

Studi Kasus: Wali Kelas X5

Kasus. Bu Rina adalah wali kelas X5. Ia memiliki data nilai empat siswa untuk tiga mata pelajaran. Bu Rina harus menghitung total nilai tiap siswa, rata-rata tiap siswa, serta nilai tertinggi dan terendah tiap mata pelajaran.

A B C D
1 Nama MTK B. Indo B. Ing
2 Budi 85 80 90
3 Ani 92 88 95
4 Cici 78 85 82
5 Dodi 90 92 87

Rumus di atas dapat disalin ke baris berikutnya dengan teknik drag atau copy-paste. Excel secara otomatis menyesuaikan alamat sel, sehingga perhitungan untuk Ani, Cici, dan Dodi menggunakan rumus yang sama.

RANGKUMAN BAGIAN 4
  • Semua rumus di Excel diawali tanda =.
  • Operator aritmatika: +, -, *, /, ^.
  • Rumus dapat merujuk ke sel lain, hasil otomatis berubah jika data diubah.
  • Fungsi bawaan: SUM, AVERAGE, MAX, MIN.

Bagian 05 · Visualisasi

Membuat Grafik (Chart)

Chart

Grafik mengubah angka-angka menjadi visual yang lebih mudah dipahami. Dengan grafik, pembaca dapat menangkap informasi penting dalam waktu singkat tanpa harus membaca seluruh tabel.

Jenis-Jenis Grafik Umum

Column / Bar

Membandingkan nilai antar kategori.

Line

Melihat tren dari waktu ke waktu.

Pie

Proporsi bagian dari keseluruhan (%).

TIPS MEMILIH GRAFIK: Bandingkan → Column / Bar. Lihat tren → Line. Lihat proporsi → Pie.

Langkah Membuat Grafik Batang

1

Blok data yang ingin dibuat grafik (contoh: A1:D5).

2

Klik tab Insert → pilih Column Chart → Clustered Column.

3

Grafik akan muncul. Atur posisinya dengan cara drag.

4

Klik grafik → klik ikon + → centang Chart Title, Axis Titles, dan Data Labels.

TIGA ELEMEN PENTING GRAFIK:

  • Chart Title — judul grafik.
  • Axis Titles — label sumbu X dan Y.
  • Data Labels — angka di atas batang.

Contoh Penerapan

Misalkan kita memiliki tabel nilai berikut, yang akan diubah menjadi grafik batang.

A B C D
1 Nama MTK B. Indo B. Ing
2 Budi 85 80 90
3 Ani 92 88 95
4 Cici 78 85 82
5 Dodi 90 92 87

Jika data di atas dibuat grafik Column Chart, akan terlihat perbandingan nilai tiap siswa pada tiga mata pelajaran. Setiap warna batang mewakili satu mata pelajaran.

Cara Membaca Grafik

1

Sumbu X (horizontal): menunjukkan kategori — pada contoh ini nama siswa.

2

Sumbu Y (vertikal): menunjukkan nilai angka.

3

Legenda: menunjukkan warna setiap mata pelajaran.

4

Tinggi batang: menunjukkan besarnya nilai.

CATATAN PENTING: Grafik Pie cocok untuk data proporsi. Untuk membandingkan nilai antar kategori, grafik Column/Bar jauh lebih tepat.

Contoh Interpretasi Grafik

  • Ani memiliki nilai tertinggi pada ketiga mata pelajaran.
  • Cici memiliki nilai terendah pada Matematika.
  • Secara umum, nilai Bahasa Inggris kelompok ini lebih tinggi dibandingkan Bahasa Indonesia.
RANGKUMAN BAGIAN 5
  • Grafik mengubah angka menjadi visual yang mudah dipahami.
  • Jenis grafik umum: Column/Bar, Line, dan Pie.
  • Pemilihan grafik harus disesuaikan dengan tujuan penyajian data.
  • Chart Title, Axis Titles, dan Data Labels membuat grafik lebih informatif.

SIMULASI INTERAKTIF

Susun Blok Rumus Excel

Seret (drag) chip rumus ke sel bergaris putus-putus — atau ketuk chip lalu ketuk sel target (sangat nyaman di HP/tablet).

Kotak Blok Rumus

Pilih rumus lalu pasangkan ke sel spreadsheet di sebelah kanan:

SUM
AVERAGE
MAX
MIN
Panduan Penempatan Zona:
  • E Kolom E (Total) baris 2–5 → Jumlah nilai tiap siswa → SUM
  • F Kolom F (Rata-rata) baris 2–5 → Rata-rata nilai tiap siswa → AVERAGE
  • 7 Baris 7 (Tertinggi) kolom B–D → Nilai tertinggi tiap mapel → MAX
  • 8 Baris 8 (Terendah) kolom B–D → Nilai terendah tiap mapel → MIN

Penjelasan Rumus Terakhir

Tips Interaktif: Anda bisa mengganti rumus kapan saja dengan menaruh chip baru di atas sel yang sama.

Rumus Dasar

TP 1 · 15 Menit

TUJUAN

Murid mampu menggunakan rumus dasar Microsoft Excel untuk menghitung total, rata-rata, nilai tertinggi, dan nilai terendah.

Langkah Kerja
1

Tambahkan kolom E = Total dan F = Rata-rata.

2

Pada sel E2, masukkan rumus: =SUM(B2:D2)

3

Salin rumus tersebut ke baris berikutnya (E3, E4, E5).

4

Pada sel F2, masukkan rumus: =AVERAGE(B2:D2)

5

Salin rumus tersebut ke baris berikutnya (F3, F4, F5).

6

Gunakan rumus berikut untuk mengetahui nilai tertinggi dan terendah mata pelajaran Matematika:
=MAX(B2:B5) =MIN(B2:B5)

Tabel Hasil
Proses Rumus Hasil
Total nilai Budi =SUM(B2:D2)
Rata-rata Budi =AVERAGE(B2:D2)
Nilai tertinggi MTK =MAX(B2:B5)
Nilai terendah MTK =MIN(B2:B5)
